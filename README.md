# Veldway live demos

Live, clickable versions of [Veldway](https://veldway.com)'s internal builds — deployed on
free infrastructure so prospects can try the engineering, not just read about it.

| Demo | Live URL | What it shows |
|---|---|---|
| [Lead Triage, Live](triage/) | https://veldway-demo-triage.veldway.workers.dev | Deterministic rules score an inbound lead (every point traceable); a model drafts the summary + reply; hostile input is quarantined and never reaches the model. |

**Honesty labeling:** these are internal builds running on sample data — not client
projects, and never presented as client results. Each page states exactly what is real
and what is simulated. The production versions of these pipelines are documented at
[veldway.com/work](https://veldway.com/work) with source at
[github.com/veldway/internal-builds](https://github.com/veldway/internal-builds).

## Lead Triage, Live — engineering notes

- `triage/src/rules.js` — the production triage rules ported from the Python internal
  build; parity pinned by `triage/test/rules.test.js` against fixtures generated by the
  Python implementation itself.
- Prose engine: Cloudflare Workers AI (Llama 3.1 8B) under a per-visitor rate limit and a
  hard daily cap; past any limit — or on any model/KV failure — the demo degrades to its
  deterministic fallback and labels the output accordingly. Spam and prompt-injection
  leads never reach a model at all.
- Privacy: pasted text is never stored or logged; the only state is anonymous rate
  counters (salted IP hash, 60 s TTL).
- Cost: Workers free plan + Workers AI free allocation (fails closed) + KV free tier — $0.

Run tests: `npm test` (parity + handler suites, no network).
Deploy: `wrangler deploy -c triage/wrangler.jsonc` (Cloudflare account with AI + KV).
